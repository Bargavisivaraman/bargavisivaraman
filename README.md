## 🪐 About

I am a Computer Science student at California State University, Northridge, building
scalable, production-ready software with a research edge.

As an **ARCS Research Fellow powered by NASA and JPL**, I architect end-to-end ML pipelines
for the Astro-Cultivator project, processing hyperspectral imagery, RealSense depth data,
and multi-sensor datasets to classify early plant stress such as drought, discoloration,
and wilting using AI-driven systems.

On the engineering side, I design and ship full-stack applications with clean architecture,
RESTful APIs, and responsive frontends, and I back them with real test suites, CI, and
security hardening rather than demos.

**Open to:** Software Engineering, Full-Stack, and Machine Learning internships and new-grad roles.
